## 📋 Project Overview

**Zoomia** is a fully functional multi-vendor e-commerce platform developed in just 3 days as a challenge to demonstrate the power of AI-assisted development. The platform enables sellers to list products, manage deliveries, offer bulk discounts, and process payments securely.

### 🎯 Challenge Goals

- ✅ Build a complete e-commerce solution in **3 days**
- ✅ Use **AI assistance** (Deepseek) for rapid development
- ✅ Implement **secure payment processing** with Paystack
- ✅ Create **seller dashboard** for inventory and order management
- ✅ Support **direct seller delivery** with city-based pricing
- ✅ Include **bulk order discounts** for quantity purchases

---

## ✨ Key Features

### For Buyers 👥
- **Location-Based Shopping** - See products deliverable to your city
- **Secure Checkout** - Paystack payment integration
- **Order Tracking** - Real-time order status updates
- **Bulk Discounts** - Automatic discounts on quantity purchases
- **Saved Addresses** - Multiple delivery address management
- **Order History** - Complete purchase history with details

### For Sellers 🛍️
- **Inventory Management** - Add, edit, and delete products
- **Delivery Zones** - Set per-city delivery pricing
- **Bulk Discount Rules** - Configure quantity-based discounts
- **Order Management** - Update order status (pending → processing → shipped → delivered)
- **Customer Insights** - View customer purchase history
- **Sales Analytics** - Track revenue and order metrics

### Platform Features 🔧
- **5% Platform Fee** - Automatically added to product prices
- **Secure Authentication** - Google OAuth login
- **Cart Persistence** - Cart saved across devices when logged in
- **Product Search** - Full-text search with filters
- **Responsive Design** - Mobile-first Tailwind CSS
